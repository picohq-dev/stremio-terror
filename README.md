# Terror por década

A Stremio addon with one catalog, **Terror**, whose filter in Discover is the decade (Anos 50 to Anos 2020).
The movies come from public MDBList lists; `build.py` turns them into static files in `site/`, and
GitHub Actions rebuilds and publishes them on GitHub Pages every day.

Install in Stremio: `https://picohq-dev.github.io/stremio-terror/manifest.json`
